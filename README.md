# 敲认真的故事

花花、狗蛋、大黄共写的北宋茶馆故事。`data/story.json` 保存 17 段公开正文与人物初见，`assets/` 保存页面使用的插图与头像。

更新正文后运行 `python3 build.py`，会在仓库根目录生成 `index.html`。GitHub Pages 选择从默认分支的根目录发布；页面资源使用相对路径，在 `/qiaorenzhen-story/` 下可直接打开。

读者可以阅读、点赞和评论；点赞数和留言保存在独立的联文服务中。服务暂时不可用时，喜欢会先记录在当前浏览器。作者通过联文服务登录后，可以翻看完整人物设定、关系图、事件图并续写正文。完整设定、口令及其他私有数据不放在这个公开仓库中。
