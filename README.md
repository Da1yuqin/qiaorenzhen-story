# 敲认真的故事

花花、狗蛋、大黄共写的北宋茶馆故事。`data/story.json` 保存 17 段公开正文与人物初见，`data/site-log.json` 保存开卷记录，`data/site-changelog.json` 保存网站功能更新，`assets/` 保存页面使用的插图与头像。

更新正文或开篇记录后运行 `python3 build.py`，会在仓库根目录生成 `index.html`。GitHub Pages 选择从默认分支的根目录发布；页面资源使用相对路径，在 `/qiaorenzhen-story/` 下可直接打开。

读者可以阅读、点赞和评论，也能在正文前切换是否显示章节作者；这个选择保存在当前浏览器。前 16 段旧稿显示「执笔待考」；第一段另标「可能是狗蛋」，其余旧章不公布未经确认的猜测。第 17 段由作者确认是花花执笔，`updatedAt` 保存腾讯文档可见的最后修订时间（2026-10-13 21:30），页面显示到分钟。此后通过作者账号发布的新章会自动显示作者头像、印章及精确到分钟的更新时间。点赞数和留言保存在独立的联文服务中；服务暂时不可用时，喜欢会先记录在当前浏览器。作者通过联文服务登录后，可以翻看完整人物设定、关系图、事件图并续写正文。完整设定、口令及其他私有数据不放在这个公开仓库中。
